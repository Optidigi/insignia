# Insignia

Shopify product customization with a merchant App Home editor, buyer storefront, signed whole-quote authorization and independent checkout validation. The current shipping scope is Lean V1; production rollout remains owner-held.

Start with [agent instructions](AGENTS.md), [implementation and acceptance](docs/architecture/implementation-plan.md), [decisions](docs/architecture/decision-ledger.md) and [delivery state](docs/delivery/state.md). The [operating model](docs/delivery/operating-model.md) governs implementation and integration; deployment and remaining resource gates are linked from current state.

Use the pinned Node, pnpm and Rust versions. Run `corepack pnpm install --frozen-lockfile`, `corepack pnpm build` and the relevant checks. `corepack pnpm check` is the integrated verification route; PostgreSQL, Function runner and browser prerequisites retain their explicit environment limits. `corepack pnpm check:types` compiles maintained projects, while `corepack pnpm check:source` rejects unapproved language/coverage drift. The permanent source guard covers all39 maintained compiler projects with zero authored untyped or unchecked TypeScript files; temporary migration allowlists are removed and exemption metadata is rejected. Final integration qualification still determines acceptance. PostgreSQL 18.6 tools found outside PATH support owned local-cluster checks; Docker process/image checks still require an available daemon.

Database qualification is separate from the integrated local route: use `corepack pnpm test:database` with an explicitly isolated migrated PostgreSQL18 target, and `corepack pnpm test:database-query-plan` for its plan control. Focused runtime, publication and renderer controls are `test:runtime`, `test:publication-stress` and `test:renderer-control`; their actual prerequisites live in the maintained scripts/package manifest. Function tooling is under `scripts/functions`, independent release tooling under `scripts/release`, and worker/runtime, lifecycle and operations/privacy code under their responsibility directories.
