# Agent roles

The [operating model](operating-model.md) controls authority, review and resource boundaries. The orchestrator owns implementation, integration and cumulative readiness; supporting agents receive bounded refs, paths, questions and permissions. Select delegation/models/effort according to task, conflict isolation and account limits.

Independent reviewers inspect affected behavior and interacting contracts. Material security/identity/money/privacy/concurrency/release-authority changes cover correctness and security. Reviews may be scoped follow-ups; prior findings retain attribution. Milestone review covers cumulative engineering/architecture. Report actual execution and isolation, never inferred isolation or fabricated approval.
