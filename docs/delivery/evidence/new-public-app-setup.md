## Protected local credentials and provider state

The new app's CLI `app info --config insignia-public --web-env --json` provided `SHOPIFY_API_KEY` and `SHOPIFY_API_SECRET`. A non-logged in-memory transfer wrote only the new app values to `/home/serveradmin/.local/share/insignia-public-app/server.env` (parent mode `0700`, file mode `0600`). This path is outside Git. Neither value was printed, copied from the old app nor committed. The public OAuth client ID above is intentionally recorded for config review; the secret is not. The local file is for later approved server use, not a hosted production secret store.

For a later approved local server run, the operator should build `spikes/m0-009` with `PUBLIC_SHOPIFY_API_KEY` set to the new public client ID, keep `server.env` readable only by this OS user, and load its `SHOPIFY_API_KEY` / `SHOPIFY_API_SECRET` into the process environment from that protected file without terminal tracing or logging. The CLI preview launcher additionally needs the observed `INSIGNIA_PUBLIC_INSTALLATION_ID`; Shopify CLI supplies its temporary `APP_URL` and `PORT`. The preview command is `corepack pnpm dev:public` in `spikes/m0-009`, with `SHOPIFY_CLI_BIN` set to the installed CLI path if it is not on `PATH`. This is an operational recipe, not permission to restart the preview outside an authorized package.

The new app's client-credentials App Events token endpoint returned HTTP 200 and an access token, but its response contained only `access_token` and `token_type`, omitting the documented top-level `scope` and `expires_in`. The existing guarded `AppEventsTokenClient` returned `null`; scope/lease were **not verified by that contract** and the token was not used. A decoded but not independently signature-verified JWT payload is not substituted for those response fields. Four token-acquisition requests total, **zero event POST attempts / zero unique events**. No billing test occurred. The public [App Events API reference](https://shopify.dev/docs/api/app-events/latest) describes the expected response fields; the observed response differs.
