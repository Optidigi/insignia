## Delivered flow

Buyers select placements, permitted logo-later or owned verified M6 artwork, independent placement overrides, decoration sizes and real size/color quantities. A shared Konva scene displays all selected placements. New price review rebuilds the complete customized subset, including retained designs; ordinary merchandise contributes no customization tier quantity. The server derives current tenant/generation/resource authority, published configuration, contextual garment price, customization tiers, setup and exact deterministic allocation. The review shows garment, unit customization and setup totals separately.

Acceptance rechecks material context, publication, inventory, entitlement and artwork before immutable persistence and whole-quote v2 signing. Command admission is committed before provider/signing work. Cached and transactional replay remain owner-bound and return the same original authorization/application. The locale-aware Ajax adapter removes only marked lines by current keys, adds authorized real-variant buckets, preserves ordinary lines and verifies readback. Unresolved writes latch before dispatch and never retry automatically. Functions remain the enforcement authority; the UI does not prove payment or checkout acceptance.

Unchanged-context renewal creates a fresh complete set/window without modifying original quote economics, FX evidence or historical carrier bytes. Changed resolved prices/design/quantity/context require complete review. Historical designs are restored from validated historical revisions; explicit new review refreshes each product's current configuration and rejects incompatible choices without silently discarding them. External cart edits require repair, not reuse of an old quantity vector.
