# Docker Official PostgreSQL mirror: primary-source notes

Checked 2026-10-09; public documentation only.

- **Publication provenance.** Docker's 2021-11-29 announcement describes its partnership with Amazon, gives the `public.ecr.aws/docker/library/<image>:<tag>` namespace using Ubuntu as the example, and says Docker automatically pushes images to ECR Public when they are updated on Docker Hub. It also warns that unauthenticated pulls outside AWS are rate limited. This supports a Docker-operated Official Images publication channel; it does not independently prove the bytes or availability of any particular PostgreSQL tag. [Docker announcement](https://www.docker.com/blog/news-from-aws-reinvent-docker-official-images-on-amazon-ecr-public/)

- **PostgreSQL repository identity.** The AWS-hosted Docker publisher gallery's search-indexed rendering identifies Docker as a verified account, alias `docker`, and lists `docker/library/postgres` as a Docker Official Image. AWS documents pull URIs as `public.ecr.aws/<registry_alias>/<repository_name>:<image_tag>`. Together these support the repository address `public.ecr.aws/docker/library/postgres`. The gallery rendering was search-indexed; direct opens of the publisher and PostgreSQL repository pages returned only a JavaScript-required shell. No manifest or tag was inspected here. [Docker publisher gallery](https://gallery.ecr.aws/docker/) · [PostgreSQL gallery destination](https://gallery.ecr.aws/docker/library/postgres) · [AWS public registry URI documentation](https://docs.aws.amazon.com/AmazonECR/latest/public/public-registries.html)

- **Independent AWS announcement.** AWS's 2021-11-29 announcement confirms Docker-published curated Official Images can be discovered through the Docker publisher gallery and describes the verified Docker publisher badge on repository pages. It states an AWS account is unnecessary to discover or pull a public image. [AWS announcement](https://aws.amazon.com/blogs/containers/docker-official-images-now-available-on-amazon-elastic-container-registry-public/)

- **Anonymous limits.** Current AWS Public service-quota documentation specifies unauthenticated image pulls at **1 per second**, non-adjustable, and unauthenticated customers at **500 GB/month**, non-adjustable. It separately lists authenticated pulls at 10/second, adjustable, and pulls to ECS, Fargate or EC2 at 10/second, non-adjustable. The table labels rates per supported Region; it does not establish the precise anonymous IP/account aggregation semantics. These limits concern ECR Public, not Docker Hub's quota. [AWS ECR Public quotas](https://docs.aws.amazon.com/AmazonECR/latest/public/public-service-quotas.html)

- **Authentication and bandwidth distinction.** AWS says no authentication is required to browse public repositories and pull images. Its pricing page separately describes 500 GB/month of anonymous free Internet data transfer, 5 TB/month when authenticated, and unlimited free bandwidth to AWS compute resources. Unlimited bandwidth is not an unlimited request rate. [AWS Gallery documentation](https://docs.aws.amazon.com/AmazonECR/latest/public/public-gallery.html) · [AWS pricing](https://aws.amazon.com/ecr/pricing/)

Evidence boundary: these citations establish documented provenance, repository naming and public pull characteristics. They do not establish current registry availability, synchronization timing, tag equivalence, platform-specific manifest equality, or successful native pulls. No credentials, registry tokens, daemon or services were used.
