The prior M8 script granted only cleanup EXECUTE. Existing owner-pool tests and a privileged session's SET ROLE did not qualify purchase processing under an ordinary worker login. The new test creates a unique synthetic LOGIN member, connects directly as that login, observes `session_user=current_user`, observes all privileged flags false, and verifies that SET ROLE to the owner is denied.
