# Merchant preview source contract — 2026-10-15

Primary-source research preceded the separately linked native read below. No provider mutation was performed.

`packages/shopify/src/catalog.ts` requests untransformed `image { url altText }`, returning catalog URLs rather than owned bytes. Shopify's Admin Image contract preserves the original, including pre-applied transforms, when no transformation is requested. Transformations are best effort. This does not establish the response format or immutable application ownership. [Admin Image, 2026-07](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/Image)

Shopify's CDN negotiates formats and may return WebP/AVIF. A filename suffix therefore does not establish actual encoding. Documented conversion includes SVG→PNG and arbitrary input→JPG/WebP; it provides no universal force-original/no-WebP guarantee. The existing isolated inspector accepts PNG/JPEG/SVG, so supported catalog references can still yield unsupported bytes. [Shopify CDN](https://cdn.shopify.io/), [Image transformation contract](https://shopify.dev/docs/api/storefront/latest/input-objects/imagetransforminput)

The initial `packages/shopify/src/catalog-image.ts` reader intentionally permits only exact `cdn.shopify.com`, public IPv4 and declared PNG/JPEG/SVG. Other Shopify hosts, IPv6 and formats are outside this bounded reader, not inherently unsupported by Shopify. Its server-selected catalog reference, no credentials/redirects, verified HTTPS hostname, public-address validation and pinned DNS lookup prevent arbitrary fetch substitution. Streaming bytes are bounded to 5 MiB. Node supports a custom `lookup`; its request timeout alone does not abort a request, so a full deadline must destroy request/response and cover DNS through body completion. [Node 24 HTTP](https://nodejs.org/docs/latest-v24.x/api/http.html#httprequestoptions-callback)

Subsequent [bounded native read](merchant-preview-native-image-read-2026-10-15.json) observed the existing fixture as a 3,990-byte PNG with recorded magic/hash, from the existing web network. This qualifies that representation only. Reader output remains uninspected: MIME headers do not replace sandbox decoding. Unsupported representations must remain explicit; do not silently change buyer-artwork policy or rewrite URL suffixes.

Future immutable previews additionally require inspected captured bytes, merchant-owned asset versions, revision bindings, reference accounting and cleanup, separate from buyer-artwork expiry. Those capabilities are not supplied by this reader. Buyer and purchase rendering must use the same frozen captured asset; existing purchases receive no current-photo backfill.
