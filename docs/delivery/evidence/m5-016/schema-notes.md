# Fixed document sources and limits

The live API remains the production-pinned `2026-07`; no version change is made. Public documentation lookup is separate from authenticated provider access. Shopify's [2026-07 Publication](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/Publication) documents `catalog`, `includedProducts`, `channels`, `autoPublish` and `supportsFuturePublishing`; inclusion does not imply effective publishing. The [2026-07 Product](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/Product) documents effective membership, `publishedOnPublication` and `unpublishedPublications`.

The browser tool could not retrieve the 2026-07 query/interface URLs (including Markdown variants). Its successful fallback [publications](https://shopify.dev/docs/api/admin-graphql/latest/queries/publications), [catalogs](https://shopify.dev/docs/api/admin-graphql/latest/queries/catalogs) and [Catalog](https://shopify.dev/docs/api/admin-graphql/latest/interfaces/Catalog) pages identify themselves as 2026-10 latest. They document CatalogType filtering and catalog-to-Publication discovery; this is documentation evidence, not a 2026-07 authenticated schema validation or completeness proof. No authenticated introspection or extra probing is authorized. Fixed Phase A requests will retain any denial/omission/error once and never change scopes or documents afterward.

Three hypotheses are distinguished by the authorized fixed reads: explicit APP publications exposes the target; APP catalogs exposes it when typed publications do not; exact-ID-only or ambiguous coverage leaves production unchanged. Historical unfiltered omission is preserved in M5-015R, not relabelled.

The production engineering bounds are 100 forward pages / 5,000 IDs / 50 nodes per page / 128 KiB bodies. The experiment additionally enforces 16 total GraphQL attempts, with one APP-catalog attempt and archive/final read reserved during APP-publication discovery, then archive/final read reserved during APP-catalog discovery. Exceeding the available experiment budget is incomplete discovery, never completeness. Every duplicate ID, malformed page, repeated/missing cursor, wrong catalog type and metadata disagreement fails qualification. A complete positive generic surface can prove discovery even if the other surface is denied; DIRECT_ONLY requires both generic surfaces complete and negative. Cleanup remains separately guarded by exact ownership/ACTIVE prestate, current identity/freshness, settled writes and intact accounting.
