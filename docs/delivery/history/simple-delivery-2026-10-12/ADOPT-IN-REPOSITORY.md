## Explicit replacements

- 50% maximum test share → optional diagnostic inventory; coverage value and maintenance cost matter.
- Attempt1-only CI → passing relevant final-candidate checks; retained failures and justified reruns.
- Every correction requires two new full-source reviews → impact-based local review; stronger independence for material risk and cumulative milestone review.
- Medium root/low every child as a lock → agent-selected available models/effort under existing account/cost limits.
- Fixed writer/delegation restrictions → agent-owned delegation and conflict isolation.
- Skill demands user-confirmed seams or a fixed reasoning ritual → delegated seam choice; techniques are adaptable guidance.
- Browser must work before further development/M5 review → explicitly deferred owner acceptance; continue independent implementation and use engineering milestone review.
- 30 seconds plus the existing bridge is immutable → reviewable freshness/composition design; no silent deployed change, restamping or relaxation of credential expiry.
- Preserve every historical wrapper in routine execution → preserve historical evidence; maintain only tools with a current job.
- All later privacy/production work implicitly belongs to M5 → active outcome and actual side effects first; full M10/M11 scope remains assigned there.

A focused inspection of the active instructions, affected check scripts and milestone criteria should find no remaining mandatory old rule for these subjects. Keep this finite: do not recursively rewrite archived transcripts, frozen native executables or every historical report. Conflicts in archived evidence are resolved by dating and removing active routing, not by falsifying the original text.

This package is a new owner-directed policy, not a claim that the repository is already reconciled. The adopting agent records what it actually changed and any unresolved substantive conflict, then continues implementation.
