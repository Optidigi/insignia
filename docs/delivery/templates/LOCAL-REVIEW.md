# Local slice review

Milestone / task / axis / repository / base / effective merge-base / head / tree:

Review the complete changed implementation and its interacting source against the current full plan, ledger and milestone charter. Apply the actual relevant skills. You are independent of the writer and read-only; do not access unallocated credentials/providers or claim tests you did not run.

Return:
- CLEAR or numbered actionable findings: severity, violated invariant, file/line, concrete counterexample, smallest correction and expected test.
- Exact inspected refs, areas and actual execution versus supplied evidence.
- Current local/native/blocked limitations and any unresolved historical security defect.
- Actual runtime metadata only where available; orchestrator verifies missing model/sandbox attestation separately.

This is LOCAL review under delegated milestone authority, not an external principal approval. On correction, review the completed new candidate rather than carrying old CLEAR forward.
