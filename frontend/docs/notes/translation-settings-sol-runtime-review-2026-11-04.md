## Findings and corrections

1. **Resolved P2, plain text was interpreted as an i18next nested lookup.** `validateCustomerWordingOverlay` accepted `$t(customer:steps.review)` as a plain message for `customer:steps.addToCart`, but `createCustomerTranslator` rendered `Review`. The implementer added `nest: false` to the canonical translation call and, after a follow-up finding, to `safeFallback` as well. The regression covers both normal authored wording and an authored unavailable message reached through invalid runtime keys or parameters. Source inspection and a rerun confirm this correction.
2. **Resolved P2, explicit Latin script received RTL direction.** `customerDirectionForLocale('ku-Latn')` returned `rtl` because an explicit non-RTL script fell through to the language-level RTL list. The implementer now gives an explicit script precedence in both directions. Regression checks cover `ku-Latn`, `ku-Arab` and `ar`; the tests pass.
3. **Resolved P2, save failure feedback was outside the viewport after clicking bottom Save.** The initial `translations-save-error-desktop.png` and `translations-save-error-mobile.png` captures showed the editor's middle/end and unchanged Save/Discard controls. The critical banner was above the visible viewport. `MerchantTranslations.save()` now schedules focus and scrolling to a `tabIndex={-1}` wrapper around that banner. Refreshed desktop, 390 and 320 captures show the failure message visibly revealed. The implementer also reports passing browser focus and viewport assertions.
4. **Resolved P2, the redesigned header tracks did not initially match the data tracks.** The first redesigned English desktop capture placed its target-language heading over the reference region. The header now has explicit full width and uses the same three tracks as the rows. Fresh captures align correctly, and the gallery test compares header/cell positions and widths.
5. **Resolved P2, long target wording was clipped inside a one-row control.** The first redesigned long-text captures exposed only the tail of the text. The public Polaris textarea now receives measured row counts from `AutoSizeTextArea`. Fresh phone captures show the full authored phrase. The regression proves expansion, replacement with short text shrinks the control, and restoration remains readable after desktop/390/320 resizing.

The initial reproduction used the existing localization artifact with absolute Node 24.21.0. The correction review runs against canonical source. The reviewer changed no application source or distribution artifact. On the follow-up assignment, the reviewer adapted `translations-gallery.test.mts` and `loading-skeleton-browser.test.mts`; the implementation owner ran those browser checks. All five material findings are resolved in the inspected code and correction captures.
