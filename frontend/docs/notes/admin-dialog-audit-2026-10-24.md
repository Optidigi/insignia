- **Outline and canvas:** view counts explicitly say “3 placements” or “1 placement.” The canvas overview control retains its useful return-to-view action, with leading padding aligned to the surrounding panel rather than a negative-margin correction.
- **Names:** full names stay in the DOM and accessible labels. Wrap instructions, errors and review names; constrain only compact resource labels. A shared overflow hook measures actual clipping, rechecks container/window resizing and font loading, and batches updates through one ResizeObserver and animation-frame queue. Existing public Polaris links/buttons get a native `s-tooltip` through `interestFor` only when clipped, without another focus stop. Native sidebar/media controls use an overflow-only browser title and retain their selection/detail or rename path for reading the full name on touch; browser titles are supplementary, not an accessible touch disclosure. Products, Orders, Methods, outline names, image captions and inspector headings use these shared primitives rather than character-count thresholds or repeated bespoke observers.

## Composition decisions

- Short confirmations, duplicate-name forms and small method choices use the public `small-100` size. Product and collection selectors explicitly retain `base`; large lists and media use larger supported sizes.
- The methods chooser has one title, placement context and enabled count. The empty library has one explanation and its recovery action in the native footer beside Cancel. A two-size price task fits its contents; more than six sizes retain a scrolling editor. Nonzero prices are not echoed below the same input.
- The image picker has one search/filter row, a separate leading count/trailing clear-selection row and one scrolling gallery. Thumbnails are framed, labels truncate, selection marks stay inside the frame, and native footer actions remain visible. The original pass used an upload tile in populated galleries; the owner correction above restores the full-width Shopify composition in all library states. No-results recovery appears before upload, keeping it visible on short phones. No private Polaris styling or new dependency was added.
- Copying keeps destination/source selection followed by a visual review. Views are selectable immediately, with Clear selection and Select all. The owner correction above replaces the original cards/side rail with compact rows and a single destination context. The optional checkbox names per-size decoration prices. Back preserves staged choices; Cancel does not write. Existing/published target setups stay protected. The copy modal now participates in the preview host’s modal isolation, preventing editor/header/footer actions behind it.
- Publication confirmation uses a product thumbnail/name/count and one consequence statement. Blocked publication exposes Review setup and specific recovery actions. Local-only publication remains explicit.
- Orders artwork previews now use a checkerboard so transparent light artwork remains visible. The production batch report identifies prepared worksheets on hold separately from excluded orders; its preparation/download semantics are unchanged. Upload type guidance is owned by the native drop zone, with the size limit stated once.

## Where dialogs belong

Artwork/design/worksheet previews and consequential removal/leave confirmations remain dialogs. No additional dialog was introduced merely to explain a setting.
