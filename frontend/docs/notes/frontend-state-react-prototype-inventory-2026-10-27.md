## Repeatable verification gap and required closure

The package currently has only `build` and `check:configs`; `scripts` contains `config-check.mjs`. Prior artifacts and README claims are not a maintained interaction suite. The migration plan therefore requires a new repeatable Node/Playwright suite using the current rewrite's installed Playwright, an explicit sibling source path/checksum and a temporary isolated Vite server. Missing sibling source must fail the full-frontend prerequisite.

It must render the 13 current scenarios and verify document edits, appearance/quantity constraints, position and removal undo, new/edit/replace/resume/switch, modal focus/Escape, local upload cancel/stale decode, review/product-return, route back/forward, and relevant desktop/390/320/light/dark/long-copy views. Pure sequence tests exercise the same document/session interfaces used by React. Build/config checks remain separate. Root CI does not automatically cover this sibling; full-frontend evidence must identify its exact source and explicit run.

## Limits

This is a source ownership map, not a passing interaction audit. It makes no production-cart, upload security, quote, payment or Shopify integration claim. Existing simulated flows remain simulated after this refactor.
