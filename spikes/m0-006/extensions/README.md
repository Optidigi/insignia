# M0-006 staging Function adapters

These targets import the unchanged M0-005 v2 Rust verifier at `../../../m0-005/rust/authorization`. They retain its complete-statement signature, carrier names, decimal parsing, member checks and `lineExpand` pricing. The 2026-07 schemas are byte-identical to M0-005. The input queries read dedicated app-owned `m0_006_public_config` and `m0_006_policy` keys, leaving historical projections untouched. Handles and UIDs are unique to this bounded experiment.

The app-owned config must set `maxBuckets` at most **10**. Both targets independently reject a larger registry value. The verifier rejects a signed count above the configured maximum. Transform then emits no partial price operations; Validation emits a checkout error. This is an experimental output admission limit, not a merchant product limit or adopted protocol. An absent product policy still has the known unsigned-allow gap described in M0-005; it is not fixed by this adapter.

`fixtures/generate.py` makes local synthetic inputs with a publicly known test seed. **Never publish this public key or its private seed to Shopify.** Live testing requires a fresh ephemeral issuer key and its own app-owned public registry. The copied 32 and 64 bucket fixtures are intentional negative cases under the ten-bucket config. The historical M0-005 64-bucket failure remains unchanged.

Local verification used pinned Rust 1.98.1, `shopify_function` 2.2.0, and Shopify CLI 4.8.2. Each target passed six native tests, `cargo clippy --all-targets --locked -- -D warnings`, and a local CLI Wasm build. The ten-signed plus 190-ordinary native fixture emitted 3,246 complete Transform JSON bytes; the 32/64 signed cases emitted no Transform operations and a Validation error. A temporary synthetic app config was used only so the CLI could discover local extensions; it was removed afterward. The CLI-built Wasm artifacts are ignored under `target/` and must be rebuilt and bound to the actual live preview by the staging operator. Local fixtures and builds prove no live cart propagation, checkout semantics or enforcement.
